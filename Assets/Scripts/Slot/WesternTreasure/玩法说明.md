# Western Treasure 游戏技术说明文档

## 一、游戏概述

Western Treasure 是一款5列卷轴老虎机游戏,融合了Wild符号收集、树成长升级、Jackpot Pick游戏和Free Spin等多种玩法元素。游戏的核心机制是通过收集Wild符号来培养一棵树,当树成长到最高等级时触发Jackpot游戏。

## 二、核心玩法系统

### 2.1 基础老虎机系统

- **卷轴布局**: 5列 x 3行
- **符号系统**:
  - Wild符号 (symbolIndex = 1): 可替代其他符号形成连线
  - Scatter符号 (symbolIndex = 0, 1): 触发Free Spin
  - T01占位符 (symbolIndex = 13): 动态替换符号
  - 普通支付符号: 其他编号符号
- **派彩方式**: 从左到右连线派彩

### 2.2 Wild收集与树升级系统

这是游戏的特色核心玩法:

#### 2.2.1 Wild收集机制

- 每次旋转中出现的Wild符号会被收集
- Wild符号通过飞行动画飞向树,增加树的成长进度
- **BaseGame模式**: 每个Wild符号增加 `treeGrow.baseWild` 点数
- **FreeGame模式**: 每个Wild符号增加 `treeGrow.freeWild` 点数
- **Buff加成**: 支持 `MultipleWildSymbolBuff`,可额外生成多个收集对象(间隔0.2秒)

**关键代码位置**:
- WesternTreasureFly.cs:41-101 (BaseGameCollectBonus方法)
- WesternTreasureReelManager.cs:214-238 (RecordBonusPositions方法)

#### 2.2.2 树的成长等级

树有4个成长等级,根据收集的Wild总数判定:

| 等级 | Wild数量范围 | 皮肤名称 |
|-----|-------------|---------|
| Level 1 | 0 ~ level2-1 | BG_Tree_1 |
| Level 2 | level2 ~ level3-1 | BG_Tree_2 |
| Level 3 | level3 ~ level4-1 | BG_Tree_3 |
| Level 4 | ≥ level4 | BG_Tree_4 |

配置数据结构(TreeGrow类):
```csharp
public class TreeGrow
{
    public int level2;  // 升到2级所需Wild数
    public int level3;  // 升到3级所需Wild数
    public int level4;  // 升到4级所需Wild数(触发Jackpot阈值)
    public int baseWild; // 基础游戏每个Wild的点数
    public int freeWild; // 免费游戏每个Wild的点数
}
```

**关键代码位置**:
- WesternTreasureSpinResult.cs:838-867 (TreeGrow类定义)
- WesternTreasureFly.cs:229-245 (ChargeTreeLevel方法)

#### 2.2.3 升级动画表现

- 达到新等级时播放"Level up"动画
- 切换到对应等级的树皮肤
- 播放音效"treelevelup"
- 进度条使用DOTween动画平滑增长

**关键代码位置**:
- WesternTreasureFly.cs:131-140 (TriggerLevelUp协程)
- WesternTreasureFly.cs:143-178 (RefreshSlider方法)

### 2.3 Jackpot Pick游戏

当Wild收集数量达到level4阈值时触发。

#### 2.3.1 触发条件

```csharp
// 触发判定
public bool isEnterJackpotFGame(int wildNum, int targetNum)
{
    return wildNum >= targetNum;
}
```

**关键代码位置**: WesternTreasureSpinResult.cs:705-712

#### 2.3.2 游戏流程

1. **初始化阶段**
   - 生成12个硬币位置
   - 服务器预先决定本轮Jackpot类型(winType)和选择次数(pickNum)
   - 预生成结果列表(jackpotList)

2. **Pick阶段**
   - 玩家点击硬币,翻开显示Jackpot类型
   - 目标是收集3个相同类型的Jackpot符号
   - 选择次数由服务器配置,通常为pickNum次

3. **结算阶段**
   - 收集到3个相同Jackpot后,展示所有未选硬币
   - 播放中奖动画和特效
   - 显示对应Jackpot弹窗(Grand/Major/Minor/Mini)
   - 清空对应Jackpot额外奖池

#### 2.3.3 Jackpot类型

| 类型 | 索引值 | 奖池名称 | 对话框类 |
|-----|-------|---------|---------|
| GRAND | 2 | GRAND | WesternTreasureGrandDialog |
| MAJOR | 3 | MAJOR | WesternTreasureMajorDialog |
| MINOR | 4 | MINOR | WesternTreasureManorDialog |
| MINI | 5 | MINI | WesternTreasureMiniDialog |

#### 2.3.4 结果生成算法

**关键代码位置**: WesternTreasureSpinResult.cs:715-746

服务器配置项:
```csharp
public class JackpotGameInfo
{
    public float Trigger_Random;        // 触发概率(已废弃,改用达到阈值触发)
    Dictionary<int, int> Reward_Random; // 中奖类型权重配置
    Dictionary<int, int> Pick_Conuts_Random; // 选择次数权重配置
    Dictionary<int, int> JackPot_Appear_Random; // 符号出现权重配置
}
```

生成步骤:
1. 根据权重随机中奖类型(jackpotType)
2. 根据权重随机选择次数(pickNum)
3. 生成3个中奖符号(前2个随机排序,第3个固定在最后)
4. 生成pickNum-3个干扰符号
5. 生成12-pickNum个未点击符号

**关键代码位置**: WesternTreasureJackpotGame.cs:74-209

### 2.4 Free Spin游戏

#### 2.4.1 触发条件

- 3个或以上Scatter符号(symbolIndex = 0 或 1)出现
- 必须从第1列开始连续出现

**关键代码位置**: WesternTreasureSpinResult.cs:165-206

#### 2.4.2 奖励规则

| Scatter数量 | 倍数奖励 |
|-----------|---------|
| 3个 | 5倍 |
| 4个 | 10倍 |
| 5个 | 50倍 |

奖励金额 = 倍数 × 当前押注

**关键代码位置**: WesternTreasureSpinResult.cs:209-228

#### 2.4.3 Free Spin特性

- Free Spin期间继续收集Wild符号
- Free Spin期间可以触发Jackpot游戏
- Free Spin期间可以重新触发获得更多次数
- Free Spin期间使用不同的符号权重配置

**关键代码位置**: WesternTreasureFreeGame.cs:26-112

### 2.5 T01符号替换系统

T01是一个特殊的占位符符号(symbolIndex = 13),会在卷轴停止后根据游戏状态动态替换为其他符号。

#### 2.5.1 替换规则

替换逻辑考虑第2列和第3列的Wild情况:

1. **判断第2列和第3列是否有Wild**
   - twoReelHaveWild: 第2列(索引1)是否有Wild
   - threeReelHaveWild: 第3列(索引2)是否有Wild

2. **替换策略**
   - 如果第3列有Wild: 替换第2、4、5列的T01
   - 如果第2列有Wild: 替换第3列的T01
   - 替换时优先选择不与第1列重复的符号

#### 2.5.2 替换算法

**关键代码位置**: WesternTreasureSpinResult.cs:478-630 (ChangeT01类)

核心逻辑:
```csharp
// 第3列有Wild时的替换
ChangeWild(threeReelHaveWild, 2, new int[]{1,3,4});

// 第2列有Wild时的替换
ChangeWild(twoReelHaveWild, 1, new int[]{2});
```

目的: 增加游戏的变化性和中奖机会,避免符号过于单一。

## 四、数据流转

### 4.1 一次完整Spin的数据流程

```
1. 玩家点击Spin按钮
   ↓
2. BaseSlotMachineController 发起Spin请求
   ↓
3. 服务器返回旋转结果 (resultContent)
   ↓
4. WesternTreasureReelManager.CreateRawResult()
   ↓
5. WesternTreasureSpinResult.ChangeResult()
   - 执行T01符号替换
   ↓
6. 卷轴开始旋转和停止
   ↓
7. WesternTreasureReelManager.ReelBounceBackHandler()
   - 记录Wild符号位置
   - 触发Wild收集飞行动画
   ↓
8. WesternTreasureFly.BaseGameCollectBonus()
   - Wild飞向树
   - 更新wildNum
   - 检查树等级,可能触发升级
   ↓
9. 检查触发条件
   - CheckHitFS(): 检查Free Spin
   - CheckHitBonus(): 检查Jackpot游戏
   ↓
10. 派彩和结算
```

### 4.2 Jackpot游戏数据流程

```
1. wildNum >= level4 触发条件满足
   ↓
2. WesternTreasureSpinResult.CheckHitBonus() 返回true
   - 生成jackpotList(12个符号)
   - 设置pickNum, winType, winMoney
   ↓
3. WesternTreasureFly.TriggerJackpot()
   - 播放树升级到level4动画
   - 播放全屏"JackPotStart"动画
   ↓
4. WesternTreasureReelManager.OpenJackpotGame()
   - 打开Jackpot游戏界面
   - 禁用Spin按钮
   ↓
5. WesternTreasureJackpotGame.EnterGame()
   - 初始化12个硬币
   - 恢复之前的点击状态(如有)
   ↓
6. 玩家点击硬币
   - WesternTreasureJackpotGame.Choose()
   - 翻开硬币显示Jackpot类型
   - clickIndex++
   ↓
7. 点击次数达到pickNum
   - ShowOtherCoin() 显示所有未点击硬币
   - 播放中奖动画
   ↓
8. 结算
   - 获取Jackpot奖励金额
   - 清空对应奖池的额外奖励
   - 打开结算弹窗
   ↓
9. 弹窗关闭后
   - WesternTreasureReelManager.CloseJackpotGame()
   - 清理Jackpot数据(ClearJackpotData)
   - 重置树到level1, wildNum=0
   - 恢复游戏状态
```

## 七、特殊机制说明

### 7.1 Buff系统支持

游戏支持 `MultipleWildSymbolBuff`,可以在收集Wild时额外生成多个收集对象:

```csharp
private int GetBuffExtraCount()
{
    int extraCount = 0;
    List<BaseBuff> activeBuffs = BuffManager.Instance.GetActiveBuffByType(
        BuffConstant.MultipleWildSymbolBuff);
    foreach (var buff in activeBuffs)
    {
        extraCount += (buff as MultipleWildSymbolBuff).GetExtraWildSymbolCount();
    }
    return extraCount;
}
```

每个额外的Wild会延迟0.2秒生成,形成连续飞行效果。

**代码位置**: WesternTreasureFly.cs:103-113

### 7.2 T01替换的策略意义

T01符号替换系统的设计目的:

1. **增加变化性**: 让每次Spin的结果更多样化
2. **提升中奖率**: 通过智能替换,避免完全不中奖的情况
3. **平衡游戏**: 根据Wild位置动态调整符号分布

替换规则考虑了第1列(树所在列)、第2列和第3列的Wild情况,确保符号分布合理。

### 7.3 Jackpot结果预生成

Jackpot游戏的结果是服务器预先生成的,客户端只是展现:

- `jackpotList`: 包含12个符号(点击的+未点击的)
- `pickNum`: 允许点击的次数
- `winType`: 中奖类型

这保证了游戏的公平性和服务器控制权。

**代码位置**: WesternTreasureSpinResult.cs:715-800

### 7.4 进度保存的完整性

游戏支持在任何状态下退出和恢复:

- **基础游戏中**: 保存当前卷轴结果和Wild累积
- **Free Spin中**: 保存剩余次数、中奖金额、卷轴结果
- **Jackpot游戏中**: 保存已点击硬币、剩余硬币、中奖状态
- **跨模式**: 支持在Free Spin中触发Jackpot的复杂状态保存

**恢复策略**:
- 优先恢复Jackpot游戏(如果isInJackpotGame为true)
- 其次恢复Free Spin(如果IsInFreespin为true)
- 最后恢复基础游戏状态

**代码位置**: WesternTreasureReelManager.cs:393-494

## 十一、总结

Western Treasure 是一款设计精巧的老虎机游戏,融合了多个流行玩法元素:

**核心亮点**:
1. **Wild收集成长系统**: 给玩家长期目标,增加粘性
2. **Jackpot Pick玩法**: 经典且受欢迎的选择类玩法
3. **多层次奖励**: 基础派彩 + Scatter奖励 + Free Spin + Jackpot
4. **完善的状态管理**: 支持任何时刻的保存和恢复
5. **丰富的视听反馈**: 动画、音效、特效配合紧密

**技术特点**:
1. 清晰的架构分层
2. 良好的数据封装
3. 灵活的配置系统
4. 完善的进度保存机制
5. 支持Buff系统扩展

游戏的核心循环是: **收集Wild → 升级树 → 触发Jackpot → 获得大奖 → 重新开始**,配合Free Spin等额外玩法,形成了丰富的游戏体验。
