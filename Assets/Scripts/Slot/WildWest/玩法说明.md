# Wild West 游戏玩法说明

## 游戏概述

Wild West 是一款野牛/野西部主题的5列4行老虎机游戏，游戏的核心特色是**挂件收集系统**和**Feature解锁系统**。玩家通过不断收集挂件，解锁5个不同的Feature页面，每解锁一个完整页面可触发强大的Super Free Spin。

---

## 核心玩法系统

### 1. 挂件收集系统（Pendant Collection）

#### 1.1 什么是挂件？

挂件是一种特殊的收集物品，出现在特定符号上，显示为带数字的图标。

- **挂件符号**：symbolIndex 16-21（共6种）
- **挂件数值**：每个挂件符号上显示一个随机数值
- **收集方式**：Spin结束后，挂件自动飞向收集按钮，累加到总挂件数

#### 1.2 挂件的获取

**基础游戏（BaseGame）**：
- 挂件符号随机出现在卷轴上
- 每个挂件符号携带的数值由 `basegame_pendant` 权重配置决定

**免费游戏（FreeGame）**：
- 挂件符号的出现频率和数值可能不同
- 数值由 `freegame_pendant` 权重配置决定

**触发FreeSpin时**：
- Scatter符号位置会变成可点击的Pick
- 玩家选择一个，获得该位置的挂件数值
- 获得的挂件会在FreeSpin结束时结算

#### 1.3 挂件的用途

挂件用于解锁**Feature收集界面**中的格子，获取奖励。

---

### 2. Feature收集解锁系统

这是游戏的核心玩法，也是最大的特色。

#### 2.1 收集界面结构

点击游戏界面上的**挂件收集按钮**，打开收集界面：

- **5个Feature页面**（Page 0-4）
- 每个页面有**9个格子**需要解锁
- 左右按钮可以切换页面
- 顶部显示当前拥有的挂件总数

#### 2.2 解锁机制

**解锁流程**：
1. 点击一个未解锁的格子
2. 消耗一定数量的挂件（每个页面有固定的挂件消耗量）
3. 翻开格子，获得奖励
4. 解锁该页面的下一个格子

**9个格子的奖励构成**：
- **7个金币奖励（COIN）**：获得金币，金币 = 倍率 × 平均投注
- **1个翻倍奖励（2X）**：下一个解锁的金币奖励翻倍
- **1个Bonus奖励（BONUS）**：立即触发Bonus Free Spin

**奖励倍率**：
- 每个格子的倍率在页面重置时随机生成
- 倍率从配置的权重池中随机抽取（不重复）

#### 2.3 页面解锁奖励

当一个页面的**9个格子全部解锁**后：

🎉 **触发 Super Free Spin**

- 页面完全解锁后立即触发
- Super Free Spin 是最强大的免费游戏模式
- 解锁该页面的下一个页面（Page 0→1→2→3→4）

#### 2.4 全部页面解锁后

当**5个页面全部解锁完成**后：

- 所有页面重置，可以重新解锁
- 进入无限循环的收集-解锁-Super Free Spin流程
- 每次重置，格子的奖励倍率和位置重新随机

---

### 3. 三种Free Spin模式

游戏有三种不同的免费游戏模式：

#### 3.1 普通Free Spin（SPIN）

**触发方式**：
- 出现 3/4/5 个 Scatter 符号（触发符号由投注等级决定）

**奖励次数**：

| Scatter数量 | Free Spin次数 |
|------------|--------------|
| 3个 | 由配置决定（例如10次） |
| 4个 | 由配置决定（例如15次） |
| 5个 | 由配置决定（例如25次） |

**特点**：
- Scatter符号会变成Pick选择
- 选择后获得挂件，并开始FreeSpin
- FreeSpin中收集的挂件会在结束时加到总数

**Retrigger机制**：
- FreeSpin期间可以重新触发
- 再次出现2/3/4/5个Scatter可增加次数
- 配置：`retrigger_freegame`

#### 3.2 Bonus Free Spin（BONUS）

**触发方式**：
- 在Feature收集界面解锁到BONUS格子

**奖励次数**：
- 每个Feature页面有固定的bonustimes配置
- 例如：Page 0 = 8次，Page 1 = 10次，等等

**特点**：
- 使用**平均投注**进行游戏（不是当前投注）
- 有特殊的Wild倍数权重配置
- 从收集界面直接进入，无需返回基础游戏

#### 3.3 Super Free Spin（SUPERFREE）

**触发方式**：
- 完全解锁一个Feature页面的9个格子后自动触发

**奖励次数**：
- 每个Feature页面有固定的times配置
- 通常比Bonus Free Spin更多

**特点（最重要）**：

1. **使用平均投注**
2. **金牛收集机制（B04符号）**：
   - 出现B04符号（金牛）会被收集
   - 收集的金牛会飞向计数器
   - 达到一定数量后提升等级

3. **H01符号替换系统**：
   - SuperFree有4个收集等级（0-3）
   - 每个等级对应需要收集的B04数量阈值
   - 达到等级后，对应的H01符号会被替换成Wild（symbolIndex=5）

   例如：
   - Level 0: H01_0 不变
   - Level 1: H01_0 → Wild
   - Level 2: H01_0, H01_1 → Wild
   - Level 3: H01_0, H01_1, H01_2 → Wild
   - Level -1(最高): 所有H01 → Wild

4. **特殊Wild倍数**：
   - 每个Feature页面有专属的Wild倍数权重配置
   - `pageInfo.wild_multiplet`

5. **升级提示**：
   - 达到新等级时显示升级动画
   - UI显示当前等级和剩余收集数

---

### 4. Wild倍数系统

#### 4.1 Wild倍数符号

Wild符号（symbolIndex = 0）可能携带倍数：

| 倍数 | SymbolIndex |
|-----|------------|
| 1x | 0 (原始Wild) |
| 2x | 24 |
| 3x | 25 |
| 4x | 26 |
| 5x | 27 |
| 8x | 28 |

#### 4.2 倍数判定

每次Spin时，Wild符号有概率变成倍数Wild：

- **BaseGame**: 使用 `basegame_wild_multiplet` 权重
- **FreeGame**: 使用 `freegame_wild_multiplet` 权重
- **Super/Bonus Free**: 使用该Feature页面的专属权重

#### 4.3 倍数计算规则

如果一个Spin中出现**多个倍数Wild**：

**所有Wild倍数相乘**

例如：
- 出现 2x, 3x, 5x → 最终倍数 = 2 × 3 × 5 = **30x**
- 该倍数应用到本Spin的所有中奖线

#### 4.4 倍数动画

- 倍数Wild会播放特殊动画
- 音效："wild_multiply"
- 卷轴停止后先展示倍数，再计算中奖

### 5. 投注等级系统（Bet Level）

#### 5.1 什么是投注等级？

根据玩家的**当前投注金额**，游戏分为3个等级：

| 等级 | 投注范围 | Scatter符号 |
|-----|---------|-----------|
| Level 0 | < Bet1 | Scatter_0 |
| Level 1 | Bet1 ~ Bet2-1 | Scatter_1 |
| Level 2 | ≥ Bet2 | Scatter_2 |

配置数据：`trigger_freegame` 列表
- triggerId: 该等级对应的Scatter符号ID
- Bet: 该等级的最低投注金额

#### 5.2 等级的影响

**1. 触发FreeSpin的符号不同**
- 不同等级，触发FreeSpin的Scatter符号ID不同
- 卷轴中的R02占位符会替换为对应等级的Scatter

**2. FreeSpin奖励次数不同**
- 每个等级配置了不同的FreeSpin次数
- 例如：
  - Level 0: 3/4/5个Scatter → 8/12/20次
  - Level 2: 3/4/5个Scatter → 12/18/30次

**3. Pick挂件数值不同**
- 每个等级的Pick挂件权重配置不同
- `triggerFreeInfo[betLevel].pendant`

#### 5.3 切换等级

**自动切换**：
- 基础游戏开始Spin前，根据当前投注自动判定等级

**提示弹窗**：

1. **首次进入游戏**：
   - 显示大弹窗（WildWestBetLevelBigDialog）
   - 展示3个等级的区别和奖励
   - 玩家选择投注金额

2. **切换投注时**：
   - 如果跨越等级阈值，显示小弹窗（WildWestBetLevelSmallDialog）
   - 提示当前所在等级
   - 可选择继续或调整

### 6. R01和R02占位符系统

#### 6.1 R02占位符（基础游戏）

- **SymbolIndex**: 23
- **作用**: 在基础游戏中替换为当前投注等级对应的Scatter符号
- **替换逻辑**: `spinresult.R02()` 返回 `triggerFreeInfo[betLevel].triggerId`

#### 6.2 R01占位符（免费游戏）

- **SymbolIndex**: 22
- **作用**: 在免费游戏中替换为配置的符号
- **替换逻辑**: 根据 `freegame_R01` 权重随机选择

---

### 7. 平均投注系统（Average Bet）

#### 7.1 什么是平均投注？

在**Bonus Free Spin**和**Super Free Spin**期间，不使用玩家的当前投注，而是使用**历史平均投注**。

#### 7.2 计算方式

- 记录玩家每次Spin的投注金额
- 统计投注分布
- 计算平均值作为Feature Free的投注金额

#### 7.3 为什么使用平均投注？

1. **公平性**: 避免玩家在低投注时触发Feature，在高投注时游戏
2. **收集奖励计算**: Feature收集界面的金币奖励 = 倍率 × 平均投注
3. **鼓励稳定游戏**: 鼓励玩家保持稳定的投注水平

#### 7.4 平均投注的应用时机

- ✅ Bonus Free Spin
- ✅ Super Free Spin
- ❌ 普通Free Spin（使用触发时的投注）

---

### 8. 符号系统

#### 8.1 特殊符号

| 符号 | SymbolIndex | 说明 |
|-----|------------|------|
| Wild | 0 | 万能符号，可替代其他符号 |
| Wild 2x | 24 | 带2倍的Wild |
| Wild 3x | 25 | 带3倍的Wild |
| Wild 4x | 26 | 带4倍的Wild |
| Wild 5x | 27 | 带5倍的Wild |
| Wild 8x | 28 | 带8倍的Wild |
| B04（金牛） | 4 | SuperFree中收集，替换H01 |
| B01（特殊） | 5 | 被替换后的符号（H01→5） |
| Pendant | 16-21 | 挂件符号（6种） |
| R01 | 22 | FreeSpin占位符 |
| R02 | 23 | BaseGame占位符 |

#### 8.2 普通符号

- **高价值符号**: 5-9
- **低价值符号**: 10-15

#### 8.3 符号替换规则

**在基础游戏中**：
1. R02（23）→ 当前等级Scatter
2. Pendant（16-21）→ 显示挂件数值

**在免费游戏中**：
1. R01（22）→ 随机符号（freegame_R01）
2. B04（4）→ 金牛收集符号
3. H01符号 → 根据等级替换为Wild（5）

## 完整游戏流程示例

### 示例1：普通Free Spin流程

1. **基础游戏**: 玩家投注1000，判定为Level 1
2. **触发**: 出现4个Scatter_1（Level 1的Scatter）
3. **Pick阶段**: 4个Scatter变成可点击格子
4. **选择**: 玩家点击第2个，获得50挂件
5. **Free Spin开始**: 获得15次免费旋转
6. **游戏中**:
   - 收集挂件符号，挂件飞向计数器
   - 可能出现Wild倍数，提升中奖
7. **Retrigger**: 出现3个Scatter，增加10次
8. **结束**: 总共游戏25次，挂件加到总数

---

### 示例2：Feature收集到Super Free流程

1. **累积挂件**: 通过多次游戏，累积了5000挂件
2. **打开收集界面**: 点击挂件按钮
3. **当前状态**: Page 2已经解锁了7个格子
4. **解锁格子8**: 消耗500挂件，翻开→获得150倍金币（= 150×平均投注）
5. **解锁格子9**: 消耗500挂件，翻开→获得BONUS
   - 立即触发Bonus Free Spin（8次）
   - 使用平均投注
   - Bonus Free结束后返回收集界面
6. **继续解锁**: 剩余挂件继续解锁Page 3
7. **完成Page 3**: 9个格子全部解锁
8. **触发Super Free**:
   - 自动触发Super Free Spin（25次）
   - 使用平均投注
   - 收集金牛（B04），解锁H01→Wild替换
9. **解锁Page 4**: Page 3完成后，Page 4自动解锁

---

### 示例3：Super Free等级提升

1. **Super Free开始**: Level初始为0
2. **第1次Spin**: 出现2个B04（金牛），飞向计数器
3. **第5次Spin**: 累积B04达到20个
4. **等级提升**: Level 0 → Level 1
   - 动画提示"LEVEL UP"
   - 以后所有H01_0符号都变成Wild
5. **第10次Spin**: 累积B04达到40个
6. **等级提升**: Level 1 → Level 2
   - H01_0, H01_1 都变成Wild
   - 中奖机会大幅提升
7. **继续游戏**: 直到25次用完

## 策略与技巧

### 1. 挂件管理策略

- **积累目标**: 每个Feature页面需要约4500挂件（9×500）完全解锁
- **优先级**: 优先解锁接近完成的页面，触发Super Free
- **BONUS时机**: 解锁到BONUS时，评估当前挂件是否够继续，避免中断

### 2. 投注等级选择

- **低预算**: Level 0，触发频率较低但成本低
- **中预算**: Level 1，平衡的选择
- **高预算**: Level 2，最高奖励，但需要更高投注

### 3. Feature解锁技巧

- **2X位置**: 2X格子后面的格子奖励会翻倍，注意解锁顺序
- **BONUS时机**: 触发BONUS前确保有足够挂件继续解锁
- **全解锁循环**: 解锁全部5个页面后，进入循环，持续触发Super Free

### 4. Super Free最大化收益

- **B04收集**: 快速提升等级，让更多H01变Wild
- **倍数Wild**: 等级高+倍数Wild = 爆分机会
- **最高等级**: Level -1（最高级）所有H01都是Wild，中奖率极高

## 数据保存与恢复

游戏支持完整的进度保存，包括：

### 保存内容

1. **挂件数量**: pendantNum
2. **Feature进度**:
   - 每个页面的解锁状态（ISUNLOCK, ISACHIEVE）
   - 每个页面当前解锁到第几个格子（infoIndex）
   - 每个格子的奖励信息（name, rate, coin）
3. **Free Spin状态**:
   - 是否在FreeSpin中
   - FreeSpin类型（SPIN/BONUS/SUPER）
   - 剩余次数
   - 当前倍数
4. **Super Free进度**:
   - 金牛收集数量（featureItem）
   - 当前等级（initLevel, freeLevel）
   - H01替换表（equalTable）
5. **平均投注数据**: userUseBet统计表

### 恢复逻辑

- 游戏启动时自动加载本地进度
- 恢复Feature页面状态
- 如果在FreeSpin中，恢复FreeSpin进度
- 如果触发了Feature Free但未开始，显示提示弹窗

## 技术实现要点

### 1. 符号替换时机

- **卷轴旋转前**: R02 → Scatter
- **卷轴停止后**: Pendant数值显示
- **FreeSpin中**: R01 → 随机符号，H01 → Wild

### 2. Wild倍数计算

```csharp
// 遍历所有Wild倍数，相乘
int MultipleValue() {
    int value = 1;
    foreach (var mul in wildMultiple.Values) {
        value *= mul;
    }
    return value;
}
```

### 3. 中奖线计算

- 使用All Ways派彩方式
- 从左到右，相邻卷轴必须有相同符号（或Wild）
- Wild可以和任何符号组合
- 最终中奖金额 = 基础派彩 × Wild倍数

### 4. Feature格子生成算法

```
1. 随机生成7个金币倍率
2. 从7个中选1个作为2X位置
3. 从剩余6个中选1个作为BONUS位置
4. 剩余5个 + 2X + BONUS = 7个位置
5. 再加上2个金币 = 9个格子
6. 随机排列顺序
```

## 常见问题（FAQ）

### Q1: 挂件上限是多少？
A: 140,000挂件（代码中的上限）

### Q2: 可以在FreeSpin中打开收集界面吗？
A: 不可以，FreeSpin期间收集界面被锁定

### Q3: 平均投注如何计算？
A: 统计玩家历史投注分布，计算加权平均值

### Q4: Super Free的最高等级是什么？
A: Level -1，表示所有H01符号都替换为Wild

### Q5: Feature页面可以跳过解锁吗？
A: 不可以，必须按顺序从Page 0开始解锁

### Q6: BONUS触发后还能继续解锁吗？
A: 可以，BONUS Free结束后返回收集界面，可继续解锁

### Q7: 全部页面解锁后会怎样？
A: 所有页面重置，可以重新解锁，无限循环

### Q8: Wild倍数有上限吗？
A: 理论上没有上限，多个Wild倍数会相乘（例如8x×8x=64x）

### Q9: 可以同时解锁多个页面吗？
A: 同时只能解锁一个页面，但可以在不同页面之间切换

### Q10: Super Free中H01什么时候替换？
A: 每次Spin结果返回时，根据当前等级自动替换

## 总结

Wild West 是一款**长线玩法**的老虎机游戏，核心乐趣在于：

1. **持续收集**: 不断收集挂件，有长期目标
2. **策略解锁**: Feature页面的解锁需要策略和规划
3. **渐进奖励**: Super Free的等级提升带来渐进式的爆发
4. **无限循环**: 全解锁后可以无限重复，持续获得Super Free

游戏的设计鼓励玩家**长时间游玩**，通过挂件系统建立长期投入感，通过Feature系统提供明确的短期目标，通过Super Free系统提供爆发性的奖励体验。

**核心循环**: 收集挂件 → 解锁Feature → 触发Super Free → 获得大奖 → 收集挂件 → ...

这是一款适合追求**收集成就感**和**长期玩法**的玩家的老虎机游戏！
